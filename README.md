# Criminal Case MS Save Manager

Backup and restore tool for the Microsoft Store version of Criminal Case.

## Features

* Create backups of your Criminal Case progress
* Restore previous backups at any time
* Return to an older save whenever you want
* Open the backup folder directly from the application
* Launch Criminal Case from within the tool

## How To Use

### Create a Backup

1. Close Criminal Case.
2. Click **Create Backup**.

### Restore a Backup

1. Close Criminal Case.
2. Click **Restore Backup**.
3. Select a backup.
4. Confirm the restore.

## Requirements

* Windows 10 or Windows 11
* Microsoft Store version of Criminal Case
